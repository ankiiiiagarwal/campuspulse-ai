# CampusPulse AI

Hackathon project: a free campus issue desk. Students report anonymously on a map. AI classifies and merges duplicates. Admins work a safety-first queue. Cost to run the demo: Rs 0.

## Spec

[CampusPulse_AI_Final_Project.md](CampusPulse_AI_Final_Project.md) — locked MVP, features, stack, and demo script.
