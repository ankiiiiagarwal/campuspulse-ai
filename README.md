# CampusPulse AI

Hackathon project: a free campus issue desk. Students report anonymously on a map. AI classifies and merges duplicates. Admins work a safety-first queue. Cost to run the demo: Rs 0.

## In this repo

- [CampusPulse_AI_Final_Project.md](CampusPulse_AI_Final_Project.md) — locked MVP spec, features, stack, and demo script
- [CampusPulse_AI_Hackathon_Presentation.pptx](CampusPulse_AI_Hackathon_Presentation.pptx) — 8-slide judge deck
- `build_hackathon_ppt.ps1` / `build_pitch_ppt.ps1` — regenerate the slides on Windows if you have PowerPoint

The web app (Next.js + Supabase + Groq) is not in this repo yet. This is the brief and the pitch.

## Stack (planned)

Next.js, Vercel, Supabase, Leaflet + OpenStreetMap, Groq Llama, MiniLM embeddings, Web Speech API.
